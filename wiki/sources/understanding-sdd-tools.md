Birgitta Böckeler's exploration of SDD tools on Martin Fowler's blog. Defines three implementation levels of SDD: spec-first (spec used for a single task), spec-anchored (spec maintained alongside code), and spec-as-source (spec is the only human-edited artifact). Reviews Kiro (lightweight, spec-first), GitHub Spec-kit (heavyweight, constitution-driven), and Tessl (spec-anchored with code generation). Raises critical questions: workflow fit for different problem sizes, review overload from markdown, false sense of control, and parallels to failed MDD approaches.
