Fission AI's OpenSpec README. A lightweight, framework-agnostic SDD library with the philosophy "fluid not rigid, iterative not waterfall." Core workflow: `/opsx:explore` (thinking partner), `/opsx:propose` (create change folder with proposal, specs, design, tasks), `/opsx:apply` (implement tasks), `/opsx:archive` (merge into main spec). Supports 30+ AI assistants. Delta spec model with ADDED/MODIFIED/REMOVED requirements. Stores feature for cross-repo planning. Compares favorably to GitHub Spec Kit (lighter) and Kiro (no vendor lock-in).
