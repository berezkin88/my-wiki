MartinLwx's practical guide on combining OpenCode with OpenSpec for SDD. Traces the evolution from LLM tab completion → vibe coding → SDD. Identifies vibe coding failure modes (context loss, assumption drift, pattern violation). Explains the three SDD levels with a spec/code maintenance comparison. Compares SDD tools (Kiro, Tessl, GitHub Spec Kit, OpenSpec) — chooses OpenSpec for its lightweight, fluid workflow. Describes OpenSpec's delta spec model (propose → apply → archive) and integration with OpenCode via slash commands.
