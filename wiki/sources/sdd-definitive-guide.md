Momčilo Popov's comprehensive SDD guide. Defines SDD as a methodology where versioned, structured specs are the source of truth and code is a regenerable output. Covers the 4-phase loop (Specify → Plan → Tasks → Implement), EARS notation for AI-readable requirements (ubiquitous, event-driven, state-driven, unwanted behavior, optional features), detailed comparison of tools (GitHub Spec Kit, AWS Kiro, Claude Code cc-sdd, Cursor Plan Mode, OpenSpec, BMAD-METHOD, Tessl, Google Antigravity), and best practices. Reports ~3-10x improvement in first-pass success rates from early adopters.
