Clojure is a dynamic, functional programming language and modern Lisp dialect that runs on the JVM. Created by Rich Hickey and released in 2007.

## Core Characteristics

- **Functional** — immutable data structures, pure functions, emphasis on simplicity
- **Homoiconic (code-as-data)** — programs are built from the same data structures the language manipulates
- **JVM-hosted** — compiles to JVM bytecode, full interop with Java libraries
- **Concurrency** — STM (Software Transactional Memory), agents, atoms — no manual locking
- **REPL-driven** — interactive development with hot-reloading
- **Macros** — compile-time code transformation for metaprogramming

## Ecosystem

- **ClojureScript** — compiles Clojure to JavaScript for frontend development
- **edn** — Extensible Data Notation, a richer alternative to JSON/XML

## Adoption

Used by Walmart (Black Friday traffic), Netflix, Apple, NASA, and Nubank (digital banking, key sponsor).
